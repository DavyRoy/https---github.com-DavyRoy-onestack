# Demo (root) · структура и ответственность

Этот каталог — «легковесная» витрина интерактивных демо‑страниц для двух ролей: user и admin. Не путать с полноценным демо‑хабом в `src/app/demo` (там сценарии Shop/Services/Booking/CRM). Здесь — изолированный набор UI‑шаблонов: шапка/сайдбар, таблицы, формы, модалки, графики.

## Маршруты
- `/demo` — лэндинг демо (выбор роли/разделов)
- `/demo/user` — витрина для пользователя
- `/demo/admin` — витрина для администратора

## Карта файлов (кто за что отвечает)

- `demo/page.tsx`: лэндинг демо. Карточки навигации по ролям и краткое описание.
- `demo/layout.tsx`: общий лэйаут демо; оборачивает страницы в `ui/DemoShell`.

- `demo/ui/`
  - `DemoShell.tsx`: определяет роль по URL (`/demo/admin*` или `/demo/user*`), рисует фон и сетку, встраивает `DemoTopbar` и `DemoSidebar`, учитывает `prefers-reduced-motion`, управляет доступностью (skip‑link, роли/aria).
  - `DemoTopbar.tsx`: верхняя панель. Мобильный бургер и дровер‑меню, центр уведомлений, меню пользователя, overlay, обработка фокуса/ESC, live‑regions.
  - `DemoSidebar.tsx`: боковая навигация. Набор пунктов для admin/user, определение активного маршрута, коллапс/expand с сохранением в `localStorage`, переключатель ролей.
  - `DemoCards.tsx`: общий UI: карточки выбора (DemoCards), `Panel`, `StatCard`, мелкие утилиты (Skeleton и пр.).
  - `DemoTable.tsx`: доступная таблица со сортировкой, пагинацией, скелетонами, клавиатурной навигацией и озвучиванием состояния.
  - `Modal.tsx`: управляемая модалка с фокус‑трапом, ESC/overlay закрытием, описаниями (`aria-labelledby/aria-describedby`), «sheet»‑режим на мобайле.
  - `inputs.tsx`: мини‑набор форм: `Label`, `TextInput`, `Select`, `Toggle` с подсказками/ошибками и aria‑связями.

- `demo/user/`
  - `page.tsx`: пользовательский дашборд. Быстрые KPI, таблица заказов, история платежей (модалка), пай‑чарт по статусам (Recharts).
  - `orders/page.tsx`: список/история заказов (чек‑листы, фильтры — демо‑уровень).
  - `notifications/page.tsx`: центр уведомлений: фильтры, пометки «прочитано», хранение состояния в `localStorage`, модалки действий.
  - `profile/page.tsx`: профиль и биллинг (демо‑инпуты, валидации на UI‑уровне).
  - `settings/page.tsx`: настройки пользователя (тогглы/селекты из `ui/inputs`).
  - `layout.tsx`: метаданные раздела user; контент уже обёрнут в общий `demo/layout.tsx`.
  - `layoutClient.tsx`: альтернативный клиентский обёртчик через `DemoShell` (в текущей маршрутизации не используется).

- `demo/admin/`
  - `page.tsx`: админ‑дашборд. KPI, Area/Bar/Pie‑чарты (Recharts), таблица последних операций, мини‑метрики.
  - `analytics/page.tsx`: аналитика по периодам (сегменты, сравнительные серии, тултипы, мини‑спарки).
  - `users/page.tsx`: список пользователей (поиск/сортировка/пагинация на клиенте; демо‑fetch `/api/demo/users`).
  - `roles/page.tsx`: роли и права (демо‑UI для RBAC сценариев).
  - `events/page.tsx`: события/аудит (демо‑таблица и фильтры).
  - `operations/page.tsx`: операционные метрики (пример листингов/панелей).
  - `security/page.tsx`: безопасность: API‑ключи, политики, аудит; локальный персист настроек (`localStorage`), модалки генерации/ротации.
  - `settings/page.tsx`: настройки админ‑панели (демо‑формы).
  - `security/layout.tsx`: метаданные/viewport для раздела «Безопасность».

## Зависимости и общие принципы
- Анимации: `framer-motion` с поддержкой `useReducedMotion`.
- Иконки: `lucide-react`.
- Графики: `recharts` (линии/площади/столбцы/пироги), dark‑tooltip стилизован локально.
- Доступность: управляемые aria‑атрибуты, фокус‑ловушки в модалках, live‑regions, клавиатурная навигация, skip‑link.
- Данные: страницы используют демо‑стаб‑данные; для примера могут обращаться к `/api/demo/*` (сами API находятся в `src/app/demo/api/*`).

## Как добавить раздел/страницу
1) Создайте файл `demo/{user|admin}/<route>/page.tsx`.
2) При необходимости — метаданные через соседний `layout.tsx`.
3) Добавьте пункт в сайдбар/мобильное меню в `ui/DemoSidebar.tsx` и `ui/DemoTopbar.tsx`.
4) Переиспользуйте `Panel`, `Modal`, `DemoTable`, компоненты из `ui/inputs`.

## Полезные входные точки
- Лэйаут и роль: `demo/ui/DemoShell.tsx`
- Навигация: `demo/ui/DemoSidebar.tsx`, `demo/ui/DemoTopbar.tsx`
- Карточки/панели: `demo/ui/DemoCards.tsx`
- Таблица: `demo/ui/DemoTable.tsx`
- Модалки: `demo/ui/Modal.tsx`
- Формы: `demo/ui/inputs.tsx`
